SMASH HOUSE — MULTI-OBJECT ART TEST REPORT
Date: August 9, 2026

ROOT CAUSE
- Object selection called the same reset path used to clear a game session.
- That path emptied the fragment array and fragment layer every time a different
  object button was chosen.
- Smash input was also blocked whenever any fragments existed, so Create Mode
  prevented a second object from being broken.
- Fragment creation replaced the prior set instead of appending a new set.

IMPLEMENTED FIX
- Added separate progress for every breakable object.
- Object selection now changes only the active target. It does not clear pieces,
  score, total hits, saved artwork, or the other objects' damage progress.
- Removed the Create Mode block that prevented smashing with existing pieces.
- New fragments append to the shared session and receive unique object-based IDs
  and layer values.
- Broken-item buttons show the actual number of pieces contributed.
- Partially damaged objects remember their exact hit count when revisited.
- The active unbroken target is raised above collected pieces for reliable mouse
  and phone tapping; collected pieces outside the target remain interactive.
- Auto Art now chooses a balanced grid for 21 to 180 pieces and reduces collision
  iterations for large collections so mixed-object layouts remain responsive.
- Mission Gallery names and saves mixed-object creations with the full shared
  fragment collection.
- Full RESET clears all object progress and fragments; no other action does.
- Added a new asset version so the previous single-object code cannot be reused
  from browser cache.

VALIDATION COMPLETED
- JavaScript syntax passed.
- Runtime session test passed for Vase, Mug, and Camera:
  • Vase break created 20 pieces.
  • Selecting Mug retained the 20 Vase pieces.
  • Partial Mug damage survived switching to Camera and back.
  • Mug break increased the retained collection from 20 to 40 pieces.
  • Partial Camera damage survived switching away and back.
  • Camera break increased the collection from 40 to 60 pieces.
  • Auto Art arranged all 60 mixed pieces across the room.
  • Mission Gallery saved all 60 pieces under a mixed-object title.
  • RESET cleared pieces, per-object progress, total hits, and gallery entries.
- Layout simulation passed for 20, 40, 60, 100, and 180 pieces on desktop and
  phone room sizes with finite, bounded coordinates.
- All three exact One Home participation bridge markers remain present once.
- Exactly 20 Vase piece references and six Vase damage-state references remain.
- All 20 approved Vase piece file hashes are unchanged.
- Defective opaque damage pictures and the white fracture-line element remain
  absent.
