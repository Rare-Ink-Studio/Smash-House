# Smashing Pumpkins Factory — isolated plug-in prototype

This directory is an **additive** development prototype inside the existing Smash House repository.

- Original `index.html` and all production assets remain unchanged.
- Open `plugins/smashing-pumpkins/index.html` locally to try the pumpkin-against-brick-wall interaction.
- `manifest.json` describes intended host integration; it is **not** an active One Home plug-in registration.
- The prototype does not connect to One Home Passport or issue tickets.
- Future integration must use host-managed authenticated participation, replay protection, and an explicit owner-approved release gate.
- Next: artwork, physics, targets, progression to Old West egg throwing, accessibility, tests, and optional host menu entry.

**Do not merge or deploy** until baseline comparison, mobile testing, participation verification, and owner approval.
